# cafe-weekly-sales-analysis

## Overview
This project analyses weekly sales data for a small cafe using Excel and present clear findings and recommendations.

## Tools Used
- Excel Worksheet
- Pivot Table
- Column Chart

## Key Findings
- Based on sales data, the highest revenue comes from food sales. The analysis shows that food sales almost twice as high as drinks sales. This suggests that food items are the main revenue driver.
- Sales are unevenly distributed across the week. Although the average daily sales are 5143, more than half of the days fall below this level. This indicates that revenue is driven by a few high-performing days.

## Business Recommendations
- The shop owner should prioritize food inventory and ensure availability.
- To improve overall performance, the shop owner could introduce promotions on low-performing days.
